Refund Policy

1. Eligibility for Refund: Refund allowed only if payment completed, overpayment occurred, or admin cancels delivery after payment.

2. When Refund is Approved: Refund is issued if admin cancels order, product is not delivered, or customer overpaid.

3. Refund Amount: Only the paid amount is refunded. No extra compensation.

4. Non-Refundable Cases: No refund if product delivered, customer cancels without admin approval, or correct payment and delivery completed.

5. Refund Process: Refund is sent to the same payment method within 3–7 business days.

6. Notes: Admin contacts customer if delivery is canceled. Customer may contact admin anytime.

7. Contact: Use Chat with admin for refund communication.
